# 快捷指令服务器

[English](README.md) | **简体中文**

**一句话说明**：让你的电脑/服务器帮 iPhone 处理照片。在 iPhone 上用一个快捷指令选好照片，几秒钟后，
处理好的照片就会自动存回你的相册，可以直接在“照片”App 里使用摄影风格。

为什么要借助电脑？效果最好的处理方式需要用到编码器，iPhone 自己运行不了。电脑上运行的是和命令行工具
完全相同的程序，所以效果也完全一样。照片只在电脑上的临时文件夹里处理，发回手机后立即删除。

> [!CAUTION]
> **只使用你自己在自己电脑上运行的服务器。**
>
> 服务器会收到你的**完整原图**。千万不要使用别人搭建的服务器，也不要使用别人发给你、指向别人服务器的
> 快捷指令：**把照片发过去，就等于把它公开到了网上**，你应该默认它会被保存、被泄露。一张原始 HEIC
> 照片里不只有画面，还有拍摄地点（GPS）、日期时间、手机型号，人物照片里甚至还有人脸和景深数据。
>
> - 如果快捷指令是别人给你的，请检查 **获取 URL 内容** 里的网址：它必须是 `shalielie.local`，或者是你
>   自己电脑的局域网地址（以 `192.168.`、`10.` 或 `172.16.`～`172.31.` 开头），也就是状态页上显示的那个。
> - 不要把你的服务器开放到互联网上（端口转发、内网穿透、云服务器都不行）。它没有登录和密码，只适合在家里的
>   局域网里使用。

## 准备工作

只需要准备一次：

1. **安装 uv**：一个帮你自动准备 Python 环境的小工具。安装方法见[主说明的“从源码安装”](../README.zh-CN.md#从源码安装)。
2. **安装 ffmpeg（推荐）**：有了它才能得到最好的效果。没有也能用，服务器会自动改用效果稍弱的
   [免编码器模式](../README.zh-CN.md#免编码器模式)，并在状态页上提示你。

## 启动服务器

双击对应系统的启动文件：

| 电脑系统        | 双击这个文件                                        |
| --------------- | --------------------------------------------------- |
| Windows         | `Start Shalielie Server.cmd`                        |
| macOS / Linux   | `start-server.command`（Linux 请在终端里运行）      |

会出现一个黑色的命令行窗口，里面显示服务器地址；浏览器也会自动打开一个**状态页**。

- **保持这个窗口开着**，服务器才会一直运行。
- **想停止时，直接关掉这个窗口**即可。

## 第一次使用时的两个授权

- **Windows** 会弹窗询问是否允许 Python 访问网络：请勾选并允许 **专用网络**。
- **iPhone** 第一次运行快捷指令时，会询问“快捷指令”能否查找并连接本地网络上的设备：请点 **允许**。

另外，**iPhone 和电脑必须连着同一个 Wi-Fi**。

## 在 iPhone 上创建快捷指令

> 小提示：电脑上的状态页里有同样的步骤，而且已经把你电脑的实际地址填好了，可以照着做。

打开 iPhone 上的 **快捷指令** App，点右上角 **＋** 新建一个快捷指令，依次添加下面四个操作：

1. **选择照片**
2. **获取 URL 内容**
   - URL：`http://shalielie.local:8765/patch`
   - 方法：**POST**
   - 请求体：**表单**
   - 点“添加新字段”，选 **文件**，键填 `photo`，值选上一步的 **照片**
3. **获取文件的详细信息**，选择 **文件扩展名**，对象是上一步的 **URL 的内容**
4. **如果**“文件扩展名”是 `heic`：
   - 那么 → **存储到相簿**（存的是“URL 的内容”）
   - **否则** → **显示结果**（这时会显示一段文字，说明这张照片为什么没有被处理）

给快捷指令起个名字（比如“摄影风格”），以后在相册里选照片、或者直接运行它就行了。

## 常见问题

**快捷指令提示连不上服务器？**

- 确认电脑上的命令行窗口还开着。
- 确认 iPhone 和电脑连的是**同一个 Wi-Fi**。访客网络，或开启了“AP 隔离”的路由器，会阻止两台设备互相访问。
- 如果 `shalielie.local` 这个名字连不上，把网址里的 `shalielie.local` 换成命令行窗口或状态页里显示的
  **IP 地址**（例如 `http://192.168.1.23:8765/patch`）。
- 电脑开着 VPN、代理软件（例如 Clash）、ZeroTier 或虚拟机时，窗口里可能显示多个地址；请使用和 iPhone
  在同一个 Wi-Fi 里的那个地址。

**快捷指令没有存照片，而是显示了一段文字？**

那段文字（英文）就是原因，常见的有：

| 文字里出现                          | 意思                                                                                   |
| ----------------------------------- | -------------------------------------------------------------------------------------- |
| `Received a JPEG` / `Not a HEIC`    | 发过去的不是原始 HEIC。请确认 iPhone **设置 → 相机 → 格式** 选的是 **高效**，并且快捷指令发送的是照片本身 |
| `already`                           | 不需要处理：这张照片已经处理过，或者是 iPhone 18 拍的，本身就带有全部功能              |
| `timed out`                         | 处理超时，通常是电脑太忙；稍后再试一次                                                 |
| 其他内容                            | 这张照片的格式暂不支持，文字里写明了原因                                               |

**处理好的照片在哪里？**

快捷指令会把它直接存进相册。在“照片”App 里编辑这张照片，就能看到摄影风格的调色板。

## 进阶：接口说明

给想自己写程序调用的用户：

`POST /patch`，请求体可以直接是 HEIC 原始数据（可选参数 `?name=photo.HEIC`），也可以是
`multipart/form-data` 表单。返回：

| 状态码 | 内容                          | 什么时候                                          |
| ------ | ----------------------------- | ------------------------------------------------- |
| 200    | 处理好的 HEIC（`image/heic`） | 响应头 `X-Shalielie-Mode` 为 `port` 或 `add-texture` |
| 409    | 文字                          | 无需处理（iPhone 18 的照片，或已处理过的照片）    |
| 415    | 文字                          | 不是 HEIC，通常是被 iOS 转成了 JPEG               |
| 422    | 文字                          | 程序拒绝处理这张照片，文字说明原因                |
| 504    | 文字                          | 处理超时                                          |

`GET /api/status` 以 JSON 返回服务器的模式、地址和最近处理的任务。

启动参数：`--port`（端口）、`--name`（局域网里显示的名字）、`--ip`（指定对外显示的地址）、
`--no-encoder`（不使用编码器）、`--no-browser`（启动时不打开浏览器）。把它们写在启动文件名后面，
或运行 `uv run --group server python shortcut-server/server.py --help` 查看说明。


## 实况照片文件对（0.7.1 测试版）

向 `/patch-live` 发送 multipart 表单，包含两个文件字段：`photo`（原始 HEIC）
和 `video`（对应的原始 MOV）。动态视频处理需要 FFmpeg。返回 ZIP，内含同名
HEIC、MOV 和 `report.json`。有编码填充边缘的视频会先裁剪有效画面，再重新编码，
以修复照片 App 风格处理中出现的底部模糊条；原文件不覆盖，音频样本保留。
报告会说明视频是否重新编码。

在“文件”中保存并解压 ZIP，然后用盘它同时导入 HEIC 和 MOV，生成新的实况照片。
快捷指令仅保存 HEIC 仍会得到静态照片；现有 `/patch` 接口继续用于静态照片。
MOV 处理失败会返回错误，不会静默退化成静态照片。iOS 真机测试版通过 Actions
构建产物提供，正式发布需待真机验证。
